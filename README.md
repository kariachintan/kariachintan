## 🧠 How I think about AI products:
- The model proposes; deterministic code disposes. Ranking, budgets, and claim checks live outside the model.
- “Degraded” is a valid status. An honest “I couldn’t” beats a confident guess.
- Facts and assumptions get different labels, in tools and in tickets.
